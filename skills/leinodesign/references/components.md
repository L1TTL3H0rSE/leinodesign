# Контракт и изменение компонентов

## Граница

Перед созданием перечисли предусмотренные операции: что потребитель меняет,
что должно сохраняться, с какими состояниями изменение совместимо.

| Форма | Критерий |
|---|---|
| Локальная композиция | Меняется вместе с конкретным экраном/сценарием |
| Приватная часть | Поддерживает инвариант владельца, собственной операции потребителя нет |
| Публичный компонент | Имеет понятное назначение; общее изменение должно достигать применений, локальное содержимое остаётся независимым |

Ни доменное имя, ни единственный потребитель не запрещают компонент.
Ни повторение, ни число экземпляров не доказывают правильность границы.
Проверь общее и локальное изменение на содержательных применениях.

## Свойства

| Операция | Представление в Figma |
|---|---|
| Изменить строку | TEXT со связью к нужному тексту |
| Показать независимую область | BOOLEAN со связью к её видимости |
| Выбрать совместимый вложенный компонент | INSTANCE_SWAP |
| Заменить свободную композицию | Native SLOT, если поддерживается каналом |
| Выбрать взаимоисключающее оформление/структуру | VARIANT |
| Менять доступную устойчивую вложенную часть | Exposed nested properties или описанная штатная операция |

Не выноси всю внутреннюю структуру наружу. Редактирование native slot на
canvas — нормальная операция; угадывание скрытого приватного пути или detach
ради предусмотренного изменения — дефект интерфейса компонента.

Условия, которые сосуществуют, не теряй в одной оси. Например, загрузка,
видимый фокус и выбранное оформление могут сочетаться. Для отражения кода
проверь, как действуют селекторы и приоритеты: hover и active могут быть
одним результирующим оформлением, а фокус — независимым эффектом.
Не навязывай интерактивные состояния неинтерактивным компонентам.

Нужные сочетания определяются контрактом и применениями. Непоказанные
сочетания перечисли; большой набор сам по себе не разрешает удалить
возможности. Различающееся содержимое обычно заменяется, а не размножает masters.

## Слоты и fallback

Настоящий SLOT должен владеть видимым содержимым: проверь дерево и замену
в instance. FRAME с названием slot и пустой SLOT рядом с текстом не эквивалентны.

Fallback задаёт значение по умолчанию, а не множество допустимого содержимого.
Проверь default, custom и empty. Выключение fallback-иконки не должно скрывать
custom content; выключение всей области — другая операция с отдельным смыслом.
После возврата состояния содержимое должно сохраниться. Пустая область
не оставляет случайное место, если контракт не требует резервирования.

Внешним расстоянием между областями владеет определённый контейнер. Проверяй
суммарный gap: два допустимых отступа могут вместе дать неправильное расстояние.
Нулевой padding допустим для таблицы/медиа с собственными отступами; обычный
текст у края без такого владельца требует пересмотра наполнения или выбора.

Служебное действие сохраняй вне заменяемого содержимого, но в раскладке
соответствующего раздела. Например, header содержит тянущуюся область заголовка
и отдельный close. Проверь длинный заголовок и скрытие раздела согласно контракту.

## Использование библиотечного компонента

До сборки проверь реальные definitions, варианты, штатные label/helper/error,
иконки и слоты. Сначала используй Size/size, включая вложенные базы; ручной
шрифт допустим при отсутствии свойства размера. Имя Small/Medium/Large между
версиями библиотеки не гарантирует одинаковые текст и геометрию.

При смене семейства/размера сохрани значения по смысловым полям, назначь
допустимые свойства внешнего и вложенного компонентов, заново получи узлы,
восстанови данные и проверь состояния, иконки, стили и Fill/Hug. Не делай
resetOverrides ради удобства: он может сбросить содержимое и выбранные значения.
Смысловые overrides сохраняй; устаревшее оформление сверяй с новой базой.

У списка переменной длины проверь добавление и удаление строк до тиражирования.
Мок из четырёх записей не требует четырёх жёстко заданных строк в компоненте.
Используй поддержанный slot или композицию экземпляров строк; число записей
не кодируй матрицей вариантов либо запасом скрытых элементов.

Не добавляй внешнюю подпись или отдельный контрол, если нужная композиция уже
предусмотрена внутри поля. Например, встроенный выбор цвета сохраняет рамку,
метку и текстовое значение; один свотч под меткой не заменяет такое поле.

## Минимальная проба изменения

До операции запиши ожидаемый общий эффект и локальные инварианты.
На одном instance измени текст, выбранную иконку или slot content; другой
должен остаться независимым. Измени ширину и длину содержимого, переключи
нужные состояния. Затем измени согласованное общее свойство master:
оба применения получают изменение, локальные overrides сохраняются.

Проверяй по реальным ID, значениям, типам, связям и снимкам, а не по названиям.
Если consumer требует автоматической починки после каждого edit, устойчивость
не подтверждена. Новая операция вне контракта — расширение задачи, не
автоматический FAIL. Изменение контракта с миграцией отличается от совместимой правки.
