# LeinoDesign

Экспериментальный навык для создания и проверки редактируемого дизайна в Figma.
Сохраняет контракт компонентов и добавляет визуальную самопроверку с реальным
наполнением. Основа — опыт Haulplane; его настройки не являются умолчаниями навыка.

## Использование

Дай агенту [skills/leinodesign/SKILL.md](skills/leinodesign/SKILL.md) и конкретную
задачу с целевым Figma-файлом. Например:

> Прочитай skills/leinodesign/SKILL.md. Создай в указанном тестовом файле
> компонент панели с редактируемым заголовком и заменяемым содержимым.
> Проверь два применения, изменение ширины и сохранность локальных настроек
> после совместимого изменения master. Сохрани результаты и снимки.

Нужны доступные инструменты чтения/записи Figma и их актуальная документация.
Навык сам не предоставляет доступ. Для read-only аудита запись не требуется.
Глобальная установка и замена навыка Haulplane не выполнялись.

## Проверка

Формат навыка проверяется штатным `quick_validate.py` из skill-creator
(Python с PyYAML; на Windows используй `python -X utf8`). Валидатор проверяет
структуру файла, а полезность проверяется реальной задачей по каталогу.
Сохранённые результаты первой пробы проверяются без внешних пакетов:

```powershell
python -X utf8 evals/trial-2026-09-08/check_trial.py good
```

Операции и исходные результаты — в [evals/trial-2026-09-08](evals/trial-2026-09-08/).
Скрипты Figma содержат IDs конкретного прогона; это журнал, не генератор
для повторного запуска поверх готового файла.

Это черновик для испытаний. Успех отдельной пробы не означает принятия
визуального направления, готовности всей библиотеки или проверки реализации.
