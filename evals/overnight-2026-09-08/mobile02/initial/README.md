## Что создано

19 продуктовых фреймов 390×844: шесть состояний основной записи на 16:00, те же состояния для доступных 14:00 и 18:00, видимый выбор второй услуги. Все тексты, поверхности и компоненты нативные. Нет растрового интерфейса или кода приложения.
Страница 0:1, название «Точка · Запись».
Основные IDs: выбор 5:2; контакты 5:45; введённый неверный телефон 8:28; ошибка 8:62; проверка 9:56; успех 9:90. Выбор голоса 10:458.
Компоненты: Button 3:33; Input 4:12; Service choice 4:23. Проба редактирования 15:182.
Полный перечень IDs, переходов и PNG находится в state.json.

## Как пройти прототип

1. На выборе нажать «Продолжить».
2. На заполненных контактах нажать «Проверить запись».
3. Проверить все данные, при необходимости «Изменить время» или «Изменить контакты».
4. «Подтвердить запись» открывает квитанцию Т-204.
5. Для ошибки: на контактах нажать поле телефона — фиксированное значение станет 123. Нажать «Проверить запись». Нажатие на поле в ошибке восстанавливает корректный номер. Имя и комментарий сохраняются. Также есть отдельная стартовая точка «Исправление телефона».
6. Доступные 14:00 и 18:00 выбираются отдельными состояниями; каждый маршрут сохраняет свой час при возврате.

## Что проверено

- Технически: все 18 полных состояний проверены против значений брифа; размеры 390×844, Inter, отсутствие текста за границами фрейма. Результат: pass. Прототип содержит 47 связей между разными верхними фреймами.
- Визуально: просмотрены полные PNG основных состояний, обзор компонентов, выбор 18:00, проверка 14:00, выбор голоса и проба редактирования. Иерархия, выбранное время, ошибка и полные реквизиты читаются. Не утверждается отдельный визуальный просмотр каждого вспомогательного дубликата.
- Редактированием: независимые TEXT overrides, переключение Error/Default и Selected No/Yes, реальное сужение QA-контейнера 640→560 (экземпляры 284→244). Длинное значение переносится в три строки. Общая правка master достигает двух экземпляров, индивидуальные подписи сохраняются. Masters восстановлены.
- Проверка контроля: корректное значение телефона принято; искусственный 123 отклонён именно по телефону, имя/комментарий остались; восстановленное значение принято. Одноразовый контроль удалён.
- В player Chrome: основной проход, ошибка и восстановление до успеха, возврат к времени, изменение контактов, выбор 14:00 и возврат из контактов с сохранением времени. Подробные маршруты в checks.json.
- Контраст рассчитан по реальным цветам: основной текст/фон 14.51:1, вторичный/фон 5.30:1, белый/primary 7.17:1, primary/tint 6.04:1, ошибка/фон 5.98:1. Это не заявление о полной доступности реализации.

## Самокоррекции и особенности инструмента

- При чтении дерева обращение к characters у FRAME отклонено. Исправлено проверкой типа TEXT; файл не менялся.
- NAVIGATE на тот же самый фрейм отклонён API. Исключены переходы уже выбранного времени к самому себе и повторный переход ошибки к самой себе; остальные связи созданы.
- После добавления веток компоненты перемещены ниже экранов на y=3100, чтобы не пересекаться с ними.
- Убрана кнопка «Готово» с успеха, поскольку отдельного действия после квитанции не задано. На выборе голоса оставлен видимый выбор и возврат к подкасту; полного сценария голоса нет согласно брифу.
- При первой проверке свежего clone API вернул неполный набор текстовых потомков. Повторное чтение в отдельном вызове загрузило полный контекст. После этого положительный/отрицательный/восстановленный контроль дали ожидаемые результаты.
- Один PNG не скачался через Invoke-WebRequest из-за DNS; curl повторно получил исходный PNG.
- Некоторые снимки player после переходов содержали чёрные/частично отрисованные области. После reload ошибка и успех показаны целиком. Переходы дополнительно подтверждены URL; непрерывная визуальная отрисовка всех переходов остаётся unknown.

## Ограничения

Это локальный дизайн-прототип с синтетическими данными, а не работающая программа. Фиксированные состояния телефона переключаются нажатием; свободного ввода, настоящей валидации или отправки формы нет. Дата фиксирована на 10 сентября 2026. Нет внешней записи, платежа, SMS, письма или уведомлений. Вторая услуга ограничена видимым выбором. На изменении времени путь проходит через контакты к проверке повторно.
Не запускались: полный player-сценарий 18:00; подтверждение 14:00 в player; player-сценарий второй услуги; клавиатура/screen reader; пользовательское исследование; реализация приложения.
Код приложения, публикация, глобальные настройки и чужие Figma-файлы не затрагивались.

## Редактирование

Button: TEXT Label; VARIANT Style.
Input: TEXT Label/Value/Helper; BOOLEAN Show helper; VARIANT State.
Service choice: TEXT Title/Details; VARIANT Selected.
Локальное содержимое меняется через свойства экземпляра. Цвета/отступы — через переменные «Точка / Основа», типографика — через шесть текстовых стилей «Точка/...». Продуктовые фреймы используют auto-layout. Для системного изменения компонента править master; содержимое экземпляров остаётся независимым.
